# TombTweaks 1.16.5 (Forge 36) — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `mc1.16.5/` — a Forge 36 build for Tombstone 7.0.0 with full parity with 1.20.1: restore, decay, book cooldowns, grave keys immune to Soulbound (including the anvil refusal), and disabled Tombstone enchantments kept out of loot and trading.

**Architecture:** An independent Gradle build in `mc1.16.5/`, compiling the shared `../core` via `srcDir`. `platform`/`feature`/`mixin` code is ported from `mc1.20.1/` using the API table below. Forge 1.16.5 runs on SRG names, so — exactly like 1.20.1 — the refmap is mandatory and the Mixin annotation processor must be declared explicitly.

**Tech Stack:** Gradle 7.6.x, ForgeGradle 5.1.x, MixinGradle 0.7, Forge 1.16.5-36.2.x, **Java 8 for everything** (toolchain 8), JUnit 5. Tombstone from CurseMaven: `curse.maven:corail-tombstone-243707:8638772` (= 7.0.0, sha256 identical to the jar the research was done on).

**Source of truth for behaviour:** `mc1.20.1/src/` + `CLAUDE.md` (invariants). The port must keep every invariant, explanatory comment, NBT key and config key.

## 🚨 The whole build is Java 8

`core` was always Java 8. On 1.16.5 the `platform`/`feature`/`mixin` code is too, so the 1.20.1 sources must be rewritten where they use newer syntax while porting:
- `x instanceof Foo foo` (pattern matching) → `if (x instanceof Foo) { Foo foo = (Foo) x; … }`;
- `var`, switch expressions, records, `List.of`/`Map.of`/`Set.of`, text blocks → Java 8 equivalents;
- the diamond operator on anonymous classes is not allowed in Java 8.
Lambdas and `java.util.function` are fine. The compiler is the check: the toolchain is 8.

## API changes: Forge 47 (mc1.20.1) → Forge 36 (mc1.16.5)

Class names on 1.16.5 are the Forge/MCP ones even with the `official` mappings channel (Mojang class names arrived in 1.17); method and field names follow the channel you pick. Use `mappings channel: 'official', version: '1.16.5'`.

| 1.20.1 | 1.16.5 |

| `Inventory` (`items`/`armor`/`offhand`) | `net.minecraft.entity.player.PlayerInventory` — check the field names in the official channel |
| `ItemStack`, `Item` | `net.minecraft.item.ItemStack`, `net.minecraft.item.Item` |

| `Containers.dropItemStack` | `net.minecraft.inventory.InventoryHelper.dropItemStack(World, double, double, double, ItemStack)` |
